## Procedimiento local de ejecución
Este checkout no incluye `project.godot` ni una instalación de Godot accesible en PATH. Tras integrar estos archivos en el proyecto Godot 4 de Papoi:

1. Configurar `res://scenes/lobby/lobby.tscn` como escena principal (o ejecutarla directamente).
2. En Windows, lanzar una instancia con `godot --path "RUTA_DEL_PROYECTO" res://scenes/lobby/lobby.tscn`; pulsar **Crear partida** en una instancia.
3. Lanzar otras instancias con el mismo comando; en cada una introducir la IP LAN del host y el puerto `2456`, y pulsar **Unirse**. Para probar en una sola máquina, usar `127.0.0.1`.
4. Repetir hasta tener host más cinco clientes. El siguiente intento debe recibir el rechazo de lobby lleno. Marcar listos a los seis para habilitar el inicio del host.
5. Para probar desconexión, cerrar una instancia cliente y comprobar que desaparece del roster. Permitir el puerto UDP seleccionado en el firewall de Windows para pruebas LAN entre equipos.
